## Usage

``` r
precision.z.test(statistic, probs = c(0.025, 0.25, 0.5, 0.75, 0.975))
```

## Arguments

- statistic:

  observed test statistic (z)

- probs:

  quantile probabilities, e.g., c(0.025, 0.975) for 95% CI (default:
  c(0.025, 0.25, 0.50, 0.75, 0.975))

## Value

- statistic:

  observed test statistic.

- probs:

  quantile probabilities.

- stat.at.probs:

  values for the test statistic at the defined probabilities.
